# DP1 — Delivery Model Commitment (2013)

**Note**: DP1 uses the same decision brief as the W1 benchmark case `edm-valley-line`. This is intentional — it allows direct comparison of the same Council run across W1 (benchmark scoring) and W4 (deep-case literature comparison) without running twice.

The brief is at:

```
evaluations/benchmark/briefs/edm-valley-line/brief.md
```

Source material, ground truth, and contemporaneous markers are at:

```
evaluations/benchmark/briefs/edm-valley-line/sources.md
evaluations/benchmark/briefs/edm-valley-line/ground-truth.md
```

## Council input for DP1

Use the `brief.md` from the benchmark case above, and the Council prompt from `benchmark/prompts/council.md`. The resulting output `benchmark/outputs/edm-valley-line/council.md` is the W4 DP1 Council run.

## W4 DP1 assessment (separate from W1 rubric)

Alongside the W1 rubric scoring, DP1 is assessed in W4 via the literature-expected comparison table in `deep-case/literature-expected.md`. That comparison is descriptive, not quantitative — it asks what MMPM literature would predict should be surfaced and whether Council surfaced it.
